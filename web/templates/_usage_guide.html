{# ── 1. 30秒看懂（展开后首屏） ── #}

30 秒看懂：这不是炒股 App，也不会帮你下单。它每天自动做一套「晨会 → 盘中检查 → 收盘复盘」的研究报告，供你阅读和决策参考。

你唯一必须做的事：每个交易日收盘后花约 5 分钟去核对——告诉系统今天猜对了还是猜错了。核对越多，Agent 才会越用越准。

{# ── 2–7. 嵌套折叠，避免页面过长 ── #}
我能用它做什么？
  • 你可以开盘前知道今天该盯什么（Driver）、偏多还是偏空（Bias）、该不该交易（Trade / Wait / No Trade）。
  • 你可以盘中（9:30–16:00）按需点 Step 2–6，检查「早上猜的对不对」——不用每一步都看，有变化时再打开。
  • 你可以收盘后（约 16:10）看 Step 7 复盘，知道「今天到底谁推动了涨跌」。
  • 你可以回顾历史相似日子——在 Cases 找类似场景，在 Playbook 看可复用的交易规则。
  • 你可以看 Agent 猜对了几次——准确率页会汇总历史命中情况。
第一次来？按这个顺序走（Day 1 新手路径）
  1. 打开首页（今日流程） → 看时间线里哪些 Step 已经变绿（已完成）。
  2. 约 8:00 后点 Morning → 读首页「决策卡」5 行 + Hypothesis，了解今天的主线判断。
  3. 9:30–16:00按需点 Step 2–6（不用全看；市场有变化或你想验证时再打开）。
  4. 约 16:10 后看 Step 7 收盘复盘，了解今天实际发生了什么。
  5. 必做：去核对页填写实际结果 → 点保存。这是让系统变准的关键一步。
  6. 有空再看看 准确率 和 Cases，建立对 Agent 水平的直觉。
每个页面一句话
  • 今日流程 — 随时看 · 当天总览、决策卡、Step 时间线，你的「控制台」。
  • Morning — 开盘前（约 8:00） · Step 1 完整晨间报告，比首页决策卡更详细。
  • 准确率 — 收盘核对之后 · 历史预测命中统计，看 Agent 靠不靠谱。
  • Cases — 想回顾时 · 按日归档的市场案例，找「今天像哪一天」。
  • Playbook — 想复盘规则时 · 从案例中提炼的可复用交易模式。
  • 历史 — 查往日时 · 浏览过去任意交易日的报告与 Step 进度。
  • 核对 — 每个交易日收盘后（必做） · 填实际走势，教 Agent 哪里猜对、哪里猜错。
决策卡怎么读？（举例）

首页「Morning 一页纸 · 决策卡」每天 5 行 + Hypothesis。下面是一个假例子，帮你理解每行含义：

Driver
「CPI 公布 + 美联储讲话」→ 今天市场由什么驱动，决定你该盯哪类新闻和数据。
Bias
「偏空」→ Agent 认为大盘方向略偏下跌；不是让你做空，而是帮你校准预期。
Trade · Wait · No Trade
「Wait」→ 今日指数与个股均不开仓，空仓是有效日。Trade = 有校准过的 setup 才动手；Wait / No Trade = 整天不交易（含个股，不只挡指数）。这只是研究参考，不保证每天盈利，下单仍由你自己决定。
失效条件
「SPY 突破前高 580」→ 如果出现这种情况，上面的 Bias 判断作废，需要重新评估。
今日只盯 · 变量 1 / 2
「10Y 收益率」「VIX」→ 盘中只需关注这两个变量，不用盯全盘。
Hypothesis
「若 CPI 低于预期，成长股反弹；若高于预期，利率敏感板块承压。」→ 今天最核心的可验证猜想，盘中和收盘后都可以对照。
休市 / 周末

NYSE 休市日（周末、法定假日）没有当日报告，这是正常的——系统不会生成 Driver、决策卡或 Step 更新。

此时请点首页的「上一交易日」链接，查看最近一份完整报告。休市期间的新闻摘要（如有）仅供参考，不构成交易决策。

常见问题
  • Agent 猜错了怎么办？ → 去核对页标错。你每一次核对都是在教它，不是投诉。
  • 要多久才会变准？ → 至少需要约 2 周的核对数据，Agent 才能从反馈中学习并调整。
  • 和 ChatGPT 有什么区别？ → 这里是结构化的每日流程（固定 Step + 决策卡），可核对（你知道它猜对几次），而且会从你的核对中学习，而不是每次从零开始聊天。
